# Mes tâches ⚡

Une to-do list perso sur le thème du film *Cars*, en HTML, CSS et JavaScript, sans dépendance.

## Fonctionnalités

- Deux listes séparées : **🏁 Pro** (Piston Cup) et **🌵 Perso** (Radiator Springs)
- Priorités basse, moyenne et haute
- Notes sur chaque tâche
- Filtres (toutes, à faire, terminées) et tri manuel ou par priorité
- Réordonner les tâches par glisser-déposer
- Barre de progression
- Thème jour / nuit avec une transition en vague
- Suppression avec « Annuler »
- Raccourcis : <kbd>N</kbd> ou <kbd>/</kbd> pour une nouvelle tâche, <kbd>←</kbd> <kbd>→</kbd> pour changer de liste

Les tâches sont enregistrées dans le navigateur (localStorage).

## Lancer

Ouvrir `index.html` dans un navigateur, tout simplement.
